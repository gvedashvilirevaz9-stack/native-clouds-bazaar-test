# ▶ Демо: как работает кнопка Play

Кнопка **▶ Демо** в нижней панели открывает список сценариев. Сценарии описаны в одном читаемом файле **`public/demo/scenarios.json`** (при сборке копируется в `web/demo/`). Рядом лежат файлы-образцы, которые сценарии «приносят» в портал.

Плеер ничего не подделывает в интерфейсе. Каждый шаг выполняется настоящими командами `window.workshop.execute(...)`, теми же, что использует агент по MCP. Поэтому любой сценарий одновременно служит работающим примером протокола агента. Действия, которые в жизни делает агент на телефоне (чтение чека, конвертация DWG, поиск цен), в сценариях заданы готовыми данными и в подписях помечены «📱 Агент (симуляция)».

Открыть демо сразу: адрес с `#demo` (например `http://127.0.0.1:8835/#demo`).

## Файлы

| Файл | Что это |
| --- | --- |
| `public/demo/scenarios.json` | сценарии: список шагов, текст подписей, данные «агента» |
| `public/demo/*.jpg, *.pdf, *.docx, *.psd, *.dwg, *.zip, *.png` | образцы: чеки, счета, инструкция, чертёж, PSD, договор, плитка, фото кухни, архив проекта |
| `src/spaces/intake/demo.ts` | движок: загрузка JSON, выполнение шагов, пауза/скорость/стоп, подстановки |
| `src/spaces/intake/DemoPanel.tsx` | меню сценариев и полоса подписи с прогрессом |
| `standalone/main.tsx` | кнопка ▶ Демо в доке и монтирование панели |

## Формат сценария

```json
{
  "schema": "workshop.demo.v1",
  "scenarios": [
    {"id": "receipts", "icon": "🧾", "title": "Чеки → сводка", "subtitle": "…",
     "steps": [
       {"say": "Человек бросает 5 чеков."},
       {"files": ["receipt-1.jpg", "receipt-2.jpg"], "category": "receipts"},
       {"cmd": "intake.data", "args": {"assetId": "$asset:receipt-1.jpg", "data": {"total": 10.7}}, "wait": 700},
       {"cmd": "intake.batch.summary", "args": {"batchId": "$batch"}},
       {"ui": "scroll", "target": "ik-summary"}
     ]}
  ]
}
```

### Типы шагов

| Шаг | Что делает |
| --- | --- |
| `{"say": "текст"}` | показывает подпись; пауза по длине текста или `wait` |
| `{"files": [...], "category"?}` | берёт файлы из `demo/` и отдаёт их в Приёмную (как при перетаскивании). Несколько файлов становятся пакетом. Шаг ждёт конца конвертации |
| `{"cmd": "...", "args": {...}}` | выполняет команду `window.workshop.execute(cmd, args)` (список команд в INTAKE.md) |
| `{"ui": "select", "asset": "$asset:имя"}` | открыть файл в Приёмной |
| `{"ui": "batch"}` | открыть текущий пакет |
| `{"ui": "tab", "value": "preview\|text\|data\|card"}` | переключить вкладку файла |
| `{"ui": "page", "value": 3}` | показать страницу 3 |
| `{"ui": "prompt"}` | раскрыть промт категории |
| `{"ui": "scroll", "target": "<data-testid>"}` | прокрутить к элементу |
| `{"ui": "click", "target": "<data-testid>"}` | подсветить кнопку и нажать её, как человек (ждёт появления до 12 с) |
| `{"ui": "service", "value": "inbox\|notebook\|sketchbook\|media\|estimate"}` | открыть вкладку Мастерской |
| `{"ui": "mode", "value": "picture\|video\|gif"}` | режим кабинета Медиа |
| `"wait": мс` | у любого шага: сколько ждать после него (делится на скорость 0.5×/1×/2×) |

### Подстановки в `args`

| Значение | Становится |
| --- | --- |
| `"$batch"` | id пакета, созданного последним шагом `files` |
| `"$asset"` | id первого файла из последнего шага `files` |
| `"$asset:имя.ext"` | id файла по имени, в том числе распакованного из ZIP |
| `"$estimate"`, `"$video"`, `"$job"`, `"$last"` | id из результата предыдущих команд: смета, видео, задача, последний ассет |
| `"$curvideo"`, `"$lastjob"` | видео, открытое сейчас; последняя задача агенту из «Что сделать?» |
| `"@file:имя.ext"` | файл из `demo/` в виде data URL (так «агент» возвращает сконвертированную картинку через `intake.attach`) |

UI-шаги общаются с интерфейсом через событие `window` `intake:ui` (`{tab}`, `{page}`, `{prompt}`). Доска сама прокручивается к новым карточкам через событие `garage:focus` (`{x, y}`).

## Сценарии

1. **Чеки → сводка расходов**: 5 фото чеков, пакет, данные, сводка по дням и товарам, доска, блокнот.
2. **Счета и инвойсы**: 2 PDF, текстовый слой, суммы к оплате и сроки, доска.
3. **Инструкция к инструменту**: PDF на 4 страницы, листание, характеристики и шаги, текст в блокнот.
4. **Чертёж + DWG + энциклопедия**: DWG не открывается в браузере, агент конвертирует, разбирает детали, вопрос «что такое контргайка» уходит в энциклопедию.
5. **Дизайн-файл PSD**: встроенное превью, плоская картинка от агента, палитра и шрифты.
6. **Договор (Word)**: текст, стороны, сроки и суммы, блокнот, метка календаря на дату начала работ.
7. **Сравнение кафеля**: 2 фото плитки, характеристики и цены, таблица сравнения на доске.
8. **Программные файлы (ZIP)**: распаковка, разбор, предупреждение о ключе в конфиге.
9. **Фото комнаты**: зоны и площади для сметы, доска, метка дня замера.
10. **Блокнот: агент пишет сам**: входящий буфер, фото, метка календаря.
11. **Смета: ремонт кухни**: материалы с фото и ценами, портал ловит нехватку шпаклёвки, правка руками, пересчёт агентом, доска.
12. **Смета: холодильник**: на сколько дней хватит на двоих, что закончится первым, список покупок в блокнот.
13. **Смета: день рождения**: порции на 12 гостей, торта не хватает, агент заменяет, итог в бюджете.
14. **Медиа: картинка**: стрелки и подписи на трещинах, скрыть, скопировать фрагмент, вставить, «Что сделать?», доска.
15. **Медиа: стереть фон**: задача агенту, PNG без фона, доска.
16. **Медиа: видео → рецепт**: кадры на паузе, «Рецепт», расшифровка, рецепт с кадрами в блокноте.
17. **Медиа: YouTube → разбор кадра**: ссылка, пауза, кадр от агента, расшифровка, задача «Разбор кадра».
18. **Медиа: детский редактор**: рисунок, наложить фото кота, наклейки, дорисовать мышкой, одна картинка.
19. **Медиа: гифка из рисунков**: 4 рисунка, бумеранг, подпись, Ч/Б, GIF на доску.
20. **Медиа: мем из кадров видео**: кадры, «Гифка / мем», подписи, GIF.
21. **Медиа: выровнять горизонт**: кривое фото, инструмент «Уровень», края подрезаны, кадрирование, доска.

«Очистить результаты» удаляет файлы Приёмной, пакеты, вложения блокнота и карточки, которые положили Приёмная и Календарь. Текст страниц блокнота остаётся.

## Добавить свой сценарий

Положите файлы в `public/demo/`, добавьте объект в `scenarios` и выполните `npm run build`. Пересобирать код не нужно, если меняется только JSON: правьте `web/demo/scenarios.json` и обновите страницу.
