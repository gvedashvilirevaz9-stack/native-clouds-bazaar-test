# Claude handoff — Sunrise Workshop

This is the isolated MySpace Workshop from the local Native Clouds version of **8 November 2026**, packaged on 9 November. It contains the original **Notebook, Sketchbook and Encyclopedia** components, their local data stores, cloud background and golden entrance objects. Marketplace, Home, Money, Study, accounts, TV remote and the avatar are not included.

**Run:** `node server.mjs`, then open http://127.0.0.1:8835. On Windows, use `START-WORKSHOP.cmd`. The prebuilt `web/` needs no npm install. To edit: `npm install`, edit source, `npm run build`.

**Main files:** `standalone/main.tsx` mounts the room; `src/spaces/garage/` contains the real editors and header; `src/spaces/personal/AskWindow.tsx` renders question cards; `src/spaces/scenes/` renders interactive SVG builds. `shared/` contains the validation and context contracts. `SOURCE-MANIFEST.json` records the copied originals.

Preserve the latest layout: one header, enlarged clock/week, Notebook-only context controls on the left, service tabs in the middle, calendar/favorites on the right. Window controls appear on hover. Full-screen covers the room header; the bottom dock stays accessible. First Encyclopedia entrance stays animated; its toggle affects later parcels.

**MCP in the original portal:** authorized tab → `get_protocol(connectionCode)` → `get_portal_state` → `execute_command` with unique requestId → `get_command_result` → verify actual state. For Encyclopedia: open the window, read presets, submit search, check its query status, save a card or scene, then open the returned item. An opened parcel is not a generated answer.

**Voice/key in the original portal:** live speech → decision router → the same controllers; a separate research/builder model generates new cards or scenes. Context narrows from L1 registry to L2 space, L3 active window and L4 selected object. Access permissions are checked separately. Preserve this design when adding an Anthropic adapter.

**This export has no network MCP server, API-key storage or paid Voice.** Its local integration seam is `window.workshop.execute(id,args)`, also exposed through the dock's Adapter / JSON importer. Search queues requests; an adapter must supply responses. Example JSON files are in `examples/`. Browser read-aloud is ordinary speech synthesis, not a live AI assistant. No secrets or personal data were copied.

See **ADAPTER-DETAILS.md** for the local facade, response workflow and provider integration; **reference/original-room-commands.json** is the original MCP schema reference, not the exported facade's supported-command list.
