# Приёмная (Inbox): вход информации в Мастерскую

Обновление от 9 ноября 2026. В Мастерской появилась четвёртая вкладка, **Inbox / Приёмная**. Это точка входа: всё, что приходит снаружи, проходит через неё и дальше отправляется на доску, в блокнот, в энциклопедию или агенту.

## Цепочка

1. **Приём.** Файл можно бросить в любое место портала, вставить через Ctrl+V или выбрать кнопкой. Текст и ссылки вставляются в поле приёмной. За один раз принимается до 50 файлов, и несколько файлов автоматически становятся **пакетом**.
   Файл, брошенный на доску, сразу ложится на доску. Брошенный в блокнот прикрепляется к открытой странице. В обоих случаях он всё равно проходит через приёмную, поэтому любой формат работает везде.
2. **Распознавание.** Формат определяется по байтам, а не по расширению.
3. **Приведение к стандарту.** Каждый файл превращается в **ассет**:
   - оригинал (хранится как есть, в IndexedDB);
   - страницы WebP: их показывают доска и блокнот, и их «видит» агент;
   - текст Markdown: его читают блокнот, поиск и агент;
   - карточка JSON: формат, размер, страницы, длительность, листы таблиц и т. д.
4. **Категория.** Отдельно от формата приёмная определяет, *для чего* этот файл: чеки, счета, инструкции, чертежи, дизайн-файлы, документы, товары, программные файлы, фото. Определяет по имени и тексту («ИТОГО», «Invoice No», «договор»…), человек может поменять. У каждой категории есть **промт и схема данных для агента**.
5. **Куда дальше:** на доску, в блокнот (картинкой или текстом), в энциклопедию с вопросом («что это за деталь?», вопрос сохраняется там), «разобраться с агентом» или скачать (оригинал, WebP, MD, JSON).

## Форматы

| Что | Как |
| --- | --- |
| JPEG, PNG, WebP, GIF, BMP, AVIF, ICO | в браузере |
| HEIC/HEIF (iPhone) | в браузере (heic2any) |
| TIFF, многостраничный TIFF | в браузере (UTIF) |
| RAW: CR2, CR3, NEF, ARW, DNG, ORF, RW2, RAF, PEF… | встроенное превью камеры (статус «частично»); полную проявку делает агент |
| SVG | растеризуется, скрипты не выполняются |
| PDF | постранично (до 40 страниц) + текстовый слой; сканы помечаются для распознавания агентом |
| DOCX, ODT, EPUB, RTF | текст полностью, первая страница картинкой |
| PPTX, ODP | обложка + слайды текстом |
| XLSX, XLS, ODS, CSV, TSV | таблицы в Markdown + картинка листа |
| TXT, MD, JSON, код, DXF/OBJ/GCODE | текст + картинка страницы |
| MP4, WebM, MOV (если кодек поддерживается) | 3 кадра + плеер |
| MP3, WAV, OGG, FLAC, M4A | волна + плеер; расшифровку делает агент |
| TTF, OTF, WOFF | образец шрифта |
| ZIP | список файлов + «Распаковать в Приёмную» |
| PSD, AI, EPS, INDD, Sketch, Figma, DWG, STEP, STL, DOC, PPT, 7z, RAR… | встроенное превью, если оно есть, иначе карточка. Статус «нужен агент» |

Ничего не теряется: если браузер не справился, оригинал хранится, и агент забирает его (`intake.page n=0`), конвертирует через свой MCP-инструмент и возвращает страницы и текст (`intake.attach`).

## Пакеты и сводки

20 чеков = один пакет. Кнопка «Запустить с агентом» отдаёт пакет агенту вместе с промтом категории. Агент заполняет данные по каждому файлу (`intake.data`), а **портал сам считает**: группирует по дням, суммирует по валютам, объединяет одинаковые товары и показывает неразборчивые поля. Сводку можно положить на доску (картинкой), в блокнот (текстом), скачать в MD или CSV.

Вид сводки зависит от категории: **ledger** (чеки, счета), **table** (чертежи, документы, товары: одинаковые колонки, чтобы сравнивать) или **notes**.

## Блокнот

- **Входящий буфер агента:** `garage.notebook.write` пишет текст в блокнот без предварительного вопроса.
- **Вложения страницы:** фото, файлы, избранное (★) и метки календаря лежат полосой под текстом. Внутрь текста они не вставляются, чтобы не сбить жёлтые метки вопросов и синие вставки ответов.
- **Экспорт:** JSON и MD теперь включают вложения. Новый экспорт PDF выводит текст и картинки (кириллица и грузинский сохраняются).
- **Исправлено:** вопрос агенту берёт тему (чип), выбранную *сейчас*. Раньше брался чип, сохранённый при создании страницы.
- В меню «спросить» добавлен Claude.

## Избранное и календарь

- В панели «Избранное» у каждой позиции рядом с «＋» (на доску) появилась кнопка «✎»: в блокнот.
- В панели «Календарь» появилась «Метка дня»: отрывной листок календаря на доску (картинкой, поэтому попадает в экспорт) или метка в блокнот. Агент: `garage.stamp`.

## Команды для агента

Все команды вызываются через `window.workshop.execute(id, args)` или панель «Adapter / JSON» внизу.

| Команда | Аргументы | Что делает |
| --- | --- | --- |
| `intake.open` | `{assetId?, batchId?}` | открыть приёмную на файле или пакете |
| `intake.list` | `{status?, category?, pendingAgent?, limit?}` | список ассетов |
| `intake.read` | `{assetId, text?, maxChars?}` | карточка + текст + данные + промт и схема категории |
| `intake.page` | `{assetId, n}` | страница WebP как data URL; `n=0` отдаёт оригинал |
| `intake.add` | `{name, dataUrl \| url \| text, category?, batchId?}` | агент приносит файл сам |
| `intake.attach` | `{assetId, pages:[dataUrl], text?, meta?}` | результат конвертации агентом |
| `intake.category` | `{assetId, category}` | поменять категорию |
| `intake.data` | `{assetId, data, reply?}` | записать извлечённые данные по схеме |
| `intake.route` | `{assetId, to:"board"\|"notebook"\|"notebook-text"\|"encyclopedia", pages?, question?}` | отправить дальше |
| `intake.request` / `intake.reply` | `{assetId, text}` | запрос пользователя агенту / ответ агента |
| `intake.extract` | `{assetId}` | распаковать ZIP в приёмную |
| `intake.categories` | — | все категории с промтами и схемами |
| `intake.batches` | — | пакеты |
| `intake.batch.create` / `.add` | `{assetIds, category?, title?}` / `{batchId, assetIds}` | собрать пакет |
| `intake.batch.read` | `{batchId}` | файлы пакета + промт + схема + шаги |
| `intake.batch.send` | `{batchId, text?}` | отдать пакет агенту (то же, что кнопка) |
| `intake.batch.summary` | `{batchId, notes?}` | посчитать и показать сводку |
| `intake.batch.route` | `{batchId, to:"board"\|"notebook"}` | сводку на доску или в блокнот |
| `garage.notebook.write` | `{text, mode?:"append"\|"replace"\|"new-leaf", heading?, date?}` | входящий буфер блокнота |
| `garage.notebook.attach` | `{assetId \| dataUrl \| url, title?}` | картинку в блокнот |
| `garage.stamp` | `{to:"board"\|"notebook", date?, caption?}` | метка календаря |

Пример полного цикла для чеков: `examples/intake-receipts.json`.

Подсказка для агента: пользователь видит запрос в доке («📥 …» или «📦 …»), а в конце сообщения стоит готовая команда для чтения (`intake.read` / `intake.batch.read`). Не объявляйте результат, пока команда не вернула состояние.

## Где код

- `src/spaces/intake/detect.ts`: распознавание по байтам.
- `src/spaces/intake/convert.ts`: конвертеры (тяжёлые библиотеки грузятся лениво, отдельными чанками).
- `src/spaces/intake/store.ts`: ассеты, пакеты, данные.
- `src/spaces/intake/categories.ts`: категории, промты, схемы, автоопределение.
- `src/spaces/intake/summary.ts`: сводки.
- `src/spaces/intake/routes.ts`: доска, блокнот, энциклопедия, агент, скачивание.
- `src/spaces/intake/commands.ts`: команды агента.
- `src/spaces/intake/IntakePane.tsx`, `intake.css`: интерфейс.
- `src/spaces/garage/notebook-media.ts`, `NotebookMedia.tsx`: вложения блокнота, буфер записи, PDF.
- `src/spaces/garage/stamp.ts`: метка календаря.

Сборка разбита на чанки: `app.js` уменьшился с 1,5 МБ до ~0,8 МБ, а pdf.js, mammoth, SheetJS, heic2any, UTIF и jsPDF подгружаются только когда нужны. Воркер pdf.js копируется в `web/vendor/`.
