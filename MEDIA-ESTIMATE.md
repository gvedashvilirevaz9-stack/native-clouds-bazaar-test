# Смета и Медиа

Обновление от 9 ноября 2026. В Мастерской две новые вкладки: **Смета** и **Медиа** (внутри три режима: Картинка, Видео, Гифка). Обе работают по одному принципу: тяжёлую работу делает агент на телефоне по MCP, а портал показывает результат, ведёт подсчёты и даёт поправить руками.

---

## Σ Смета

Одна форма для любого «сколько нужно / сколько стоит / на сколько хватит».

Шаблоны: **Ремонт и материалы**, **Продукты и запасы**, **Событие**, **Детали и комплектующие**, **Своя смета**. У каждого шаблона свой промт для агента (кнопка «промт для агента»).

Строка сметы:

| Поле | Смысл |
| --- | --- |
| `group` | раздел: «Стены», «Пол», «Купить»… |
| `name`, `image`, `shop`, `url` | товар с фото и ссылкой на магазин |
| `qty`, `unit`, `unitPrice`, `total?` | количество, единица, цена; `total` задаётся, если магазин продаёт упаковками |
| `covers {value, unit}` | **на что хватит**: 25 м², 12 чел., 3 дн., 1 мотор |
| `basis` | откуда взялось количество: «8,5 кг/м² × 25 м² + 10%» |
| `status` | `ok`, `check` (проверить), `missing` (купить), `have` (уже есть, в сумму не входит) |

У сметы есть **цель**: `target {label, value, unit}`, например «Стены 25 м²», «Гостей 12 чел.», «Людей 2 чел.».

**Что портал считает сам:**
- итог и суммы по группам (позиции «есть» в итог не входят);
- **узкое место**: строка, которая покрывает меньше всех в единице цели;
- **не хватает на цель**: строки, где покрытие меньше цели (подсвечены красным);
- **закончится первым**: если у всех строк одна единица покрытия, например «дн.»;
- при ручной правке количества покрытие пересчитывается пропорционально (2 мешка → 3 мешка = в 1,5 раза больше м²), а строка помечается как изменённая. Кнопка «Пересчитать с агентом» отправляет смету агенту на проверку.

**Выход:** карточка на доску (картинкой с фото товаров), текст в блокнот, MD, CSV, JSON.

## ◐ Медиа

### ✂ Картинка

Лёгкий редактор, где всё является слоями, а при сохранении склеивается в одну картинку.

- **Инструменты:** двигать, выделить, обрезать, **уровень**, стрелка, рамка, овал, маркер, карандаш (рисовать мышкой, толщина до 40), текст, скрыть (пикселизация).
- **Наложить:** «Фото сверху» берёт другую картинку из Приёмной или файл, кладёт её слоем, дальше её можно двигать и уменьшать за угол. Плюс наклейки-эмодзи (⭐ ❤️ 🌈 🐱…), которые тоже двигаются и растягиваются.
- **Выделение:** копировать, вырезать, вставить слоем (Ctrl+C/X/V), «обрезать по выделению», «фрагмент → Приёмная». Картинка, вставленная из буфера в режиме редактора, становится слоем.
- **Уровень (выровнять горизонт):** ползунок наклона ±45° с шагом 0,1°, кнопки ±0,5° и сетка поверх картинки. Инструмент «Уровень»: проведите линию вдоль того, что должно быть ровным (горизонт, край стола, стена), и картинка повернётся так, чтобы линия стала горизонтальной (или вертикальной, если она ближе к вертикали). Края подрезаются автоматически, пустых углов нет. Это не портит исходник: угол можно поменять в любой момент, потом обрезать.
- **Изображение:** поворот 90°, отражение, яркость, контраст, цвет, **Ч/Б одной кнопкой**, **Мем** (подпись сверху и снизу белым жирным текстом с обводкой).
- Слои: список, выше/ниже, удалить, отмена и повтор (Ctrl+Z / Ctrl+Shift+Z).
- **Готово:** на доску, в блокнот, в Приёмную, PNG. Кнопка **«Что сделать с картинкой?»** открывает сценарии на выход (см. ниже).

### 🎞 Видео

- Вставьте **ссылку YouTube**: плеер открывается прямо в кабинете. Или выберите **видеофайл из Приёмной**.
- **На паузе** кадр сохраняется с таймкодом (галочка «Кадр при паузе»), и сразу открывается вопрос «что сделать с кадром?». Есть и кнопка «📸 Достать кадр».
- Кадры лежат лентой: заметка к кадру, выбор галочкой, клик переходит к моменту в видео. «Что сделать из выбранных (N)» работает сразу с несколькими кадрами.
- **Расшифровка**: агент приносит текст с таймкодами, клик по строке перематывает видео.

**Как достаётся кадр.** Из видеофайла кадр берётся прямо из плеера. YouTube-плеер — чужой фрейм, и прочитать его пиксели страница не может, поэтому есть два пути:
1. **«Захват вкладки»**: браузер один раз спрашивает разрешение на показ этой вкладки, дальше кадры вырезаются из области плеера мгновенно (Chrome/Edge).
2. **Через агента**: момент отмечается в ленте как «ждёт агента», а агент достаёт кадр по ссылке и таймкоду у себя и присылает его командой `video.frame`.

Там, где сайт YouTube запрещён (например, в превью claude.ai), вместо плеера появляется подсказка, а кадры и расшифровка всё равно приходят от агента.

### 🌀 Гифка

- Источники: несколько картинок (рисунки, фото, пакет из Приёмной) или кадры из видео (сценарий «Гифка / мем»).
- Порядок кадров ← →, скорость (0,06–2 с на кадр), ширина, формат кадра (как у первой, 1:1, 4:3, 16:9, 9:16), вписать или заполнить, **Ч/Б**, **бумеранг**, **мем-подпись** сверху и снизу.
- Сохранение: **GIF** (gifenc в браузере), **MP4** (если браузер умеет записывать MP4, иначе WebM) и **WebM**. Результат ложится в Приёмную, а на доске и в блокноте GIF показывается анимированным.
- MP3 — это только звук, у гифки его нет. Звук к MP4 может наложить агент.

### ✨ Сценарии на выход: «Что сделать?»

Общие для картинок и кадров, описаны в `src/spaces/picture/outputs.ts`, там же промт и куда агенту класть результат.

| Сценарий | Кто делает |
| --- | --- |
| Гифка / мем, На доску, В блокнот, PDF-раскадровка | портал, сразу |
| Документ, Рецепт, Меню, Презентация, Книжка, Пошаговая инструкция, Разбор кадра (кинокритик), Объяснить (в энциклопедию), Стереть фон, Посчитать (смета) | агент: получает картинки, таймкоды, промт и уточнение человека |

Задача агенту — это «job»: `media.job.read` отдаёт промт, правило доставки и список картинок (каждую можно взять через `intake.page`), а `media.job.reply` закрывает задачу.

## Команды агента

| Команда | Аргументы |
| --- | --- |
| `estimate.templates` | — (шаблоны, промты, форма строки) |
| `estimate.list` / `estimate.read` / `estimate.open` | `{estimateId}` |
| `estimate.create` | `{template, title, currency, target, items[], assumptions[], sources?}` |
| `estimate.patch` | `{estimateId, …поля}` |
| `estimate.item` | `{estimateId, item}`: добавить или обновить строку (по `id` или по имени и группе) |
| `estimate.item.remove` | `{estimateId, itemId}` |
| `estimate.request` | `{estimateId, text}`: «пересчитай» от человека |
| `estimate.route` | `{estimateId, to:"board"\|"notebook"}` |
| `picture.open` | `{assetId, page?}` или `{dataUrl\|url, name}` |
| `picture.annotate` | `{objects:[{type:"arrow",a,b} \| {type:"rect"\|"ellipse"\|"highlight"\|"pixelate", r} \| {type:"pen", pts} \| {type:"text", at, text, size?, meme?}]}` в пикселях картинки |
| `picture.crop` / `picture.rotate` | `{rect}` / — |
| `picture.level` | `{angle}` (−45…45°) или `{line:{a:{x,y}, b:{x,y}}}`: выровнять по линии |
| `picture.copy` / `picture.cut` / `picture.paste` | `{rect}` / `{rect}` / `{dataUrl?, at?}` |
| `picture.save` | `{to?:"board"\|"notebook", rect?}`: сохраняет новой картинкой в Приёмную |
| `video.open` | `{url}` (YouTube) или `{assetId}` (файл) |
| `video.seek` / `video.capture` | `{t}` / `{t?, note?, ask?}`: кадр сейчас или «ждёт агента» |
| `video.frame` | `{videoId, t, dataUrl}`: агент присылает кадр |
| `video.transcript` | `{videoId}`: запрос; `{videoId, segments:[{t,text}]}`: ответ |
| `video.output` | `{videoId, output, frameIds?, text?}` |
| `gif.load` | `{assetIds}` или `{videoId, all?}` |
| `gif.set` | `{delay, width, ratio, fit, bg, grayscale, boomerang, top, bottom, textSize}` |
| `gif.export` | `{format:"gif"\|"mp4"\|"webm", to?}` |
| `media.outputs` / `media.run` / `media.ask` | список сценариев / запустить `{output, assetIds, text?}` / показать диалог |
| `media.jobs` / `media.job.read` / `media.job.reply` | задачи агенту |

## Где код

- `src/spaces/estimate/`: `store.ts` (модель, подсчёты), `routes.ts` (доска, блокнот, MD/CSV, запрос агенту), `EstimatePane.tsx`, `estimate.css`.
- `src/spaces/picture/`: `model.ts` (документ картинки, слои, отмена), `render.ts` (отрисовка, копировать/вставить, сохранение), `PicturePane.tsx`, `video.ts` (YouTube IFrame API, файлы, захват вкладки, кадры, расшифровка), `gif.ts` (GIF/MP4/WebM), `outputs.ts` (сценарии на выход), `run.ts` (выполнение сценариев и задачи агенту), `MediaPane.tsx`, `commands.ts`, `picture.css`.
- Демо: 11 новых сценариев в `public/demo/scenarios.json` (смета ×3, медиа ×8). Описание формата в DEMO.md.
