# Sunrise Workshop — отдельная комната MySpace

Срез локальной версии Native Clouds от 8 ноября 2026, упакован 9 ноября. Только комната: **Блокнот, Скетчбук, Энциклопедия**. Это рабочие компоненты проекта, а не перерисованный макет.

## Открыть

1. Распаковать ZIP полностью в любую папку.
2. Запустить `START-WORKSHOP.cmd` (нужен установленный Node.js).
3. Открыть **http://127.0.0.1:8835**. Оставить окно сервера открытым; остановка — Ctrl+C.

Готовая сборка уже в `web/`: `npm install` для просмотра не нужен. Двойной щелчок по HTML через `file://` не поддерживается — нужен локальный сервер. Если порт занят: `node server.mjs 8836`, затем открыть соответствующий адрес. На macOS/Linux: `node server.mjs`.

## Что проверить

- Блокнот → золотая книга → **Open your package** → новая страница → написать → сохранить.
- Скетчбук → золотой атлас → **Open your package** → стикер / заметка / изображения / страницы доски.
- Энциклопедия → дирижабль → **Open your package** → встроенная демонстрация велосипеда. Внутри шесть разделов: как работает, кто, что, где, как сделать, что выбрать.
- Навести мышь на заголовок рабочего окна: появятся действия **по ширине / на весь экран**. В Энциклопедии там же анимация и библиотеки провайдеров. Без наведения остаются название и дата.
- В нижней панели — язык и **Адаптер / JSON**. Там можно посмотреть запрос, отправленный из поиска, и импортировать ответ агента. Примеры — в `examples/`.

## Новое: Приёмная (9 ноября)

Четвёртая вкладка **Inbox / Приёмная**. Бросьте файл в любое место портала (или Ctrl+V): он распознаётся, конвертируется в браузере (фото, HEIC, RAW, PDF, DOCX, XLSX, PPTX, видео, аудио, шрифты, ZIP…) и спрашивает, куда его отправить дальше. Категории (чеки, счета, инструкции, чертежи…) несут промт для агента, а пакет из 10–50 файлов превращается в сводку. Блокнот принимает картинки, избранное и метки календаря, экспортируется в PDF, а агент может писать в него напрямую. Подробно: **INTAKE.md**. Вкладки **Медиа** (картинка, видео/YouTube, гифка) и **Смета** описаны в **MEDIA-ESTIMATE.md**. Кнопка **▶ Демо** внизу показывает 21 сценарий по шагам; формат сценариев описан в **DEMO.md**.

## Важная граница

**MCP-сервер, платный Voice и генератор новых AI-карточек в этот экспорт не включены.** Они относятся к серверной части общего портала. Поиск внутри комнаты записывает запрос в буфер; без подключённого адаптера ответ сам не появится. Библиотеки ChatGPT/Grok/Anthropic/Gemini — источники карточек, а не кнопки авторизации в этих сервисах.

Для Claude оставлен локальный программный вход `window.workshop.execute(...)`, форматы карточек/сборок, исходные схемы команд и краткое объяснение MCP/Voice в **HANDOFF-CLAUDE.md**. Он может экспериментировать с комнатой и добавить свой адаптер. Чтение готового текста через доступные голоса браузера — отдельная функция, это не платный AI-звонок.

Небо, облака, золотые объекты, редакторы и встроенный велосипед доступны без внешнего портала. Внешние изображения, карты, ссылки и видео требуют интернета; серверные поисковые функции общего портала недоступны. Избранное внешнего Marketplace не переносилось, поэтому этот список изначально пуст.

Записи этой копии сохраняются в localStorage/IndexedDB **её адреса в браузере**. Используйте один порт для продолжения работы. Личные записи, ключи, кошельки, логи и подключения основного портала в ZIP не переносились. Исходный стенд не изменён и не запущен.

## Редактировать

```text
npm install
npm run build
npm start
```

`standalone/main.tsx` — оболочка и локальный адаптер; `src/spaces/garage/` — оригинальные редакторы и оформление комнаты; `src/spaces/personal/AskWindow.tsx` — карточки; `src/spaces/scenes/` — интерактивные сборки; `shared/` — форматы и контекст; `public/` — изображения. После правок пересобрать `web/`.
