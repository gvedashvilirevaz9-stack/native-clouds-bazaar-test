# Фон №3 — Игра «Лила» (живой десктоп-фон с игрой)

Третий живой фон. Самодостаточная HTML-игра поверх обоев. Не играешь — просто
десктоп с фоном и фишкой; нажал «Войти в игру» — над фоном поднимается стеклянная
доска, и начинается настоящая «Лила» (один кубик, вход на 6, карта-зеркало, заметка,
журнал).

## Файлы

- `public/livebg/lila.html` — вся игра: разметка, стили (inline `<style>`) и логика
  (inline `<script>`). Один файл, без сборки.
- `public/livebg/lila-board.js` — данные: массив `LILA_BOARD` (72 клетки) + тексты
  зеркал/вопросов. Экспортит `window.LILA_BOARD`, `window.LILA_PLANS`.
- `public/livebg/lila/` — ассеты (webp/jpg): `board.jpg` (фон-доска), `card-frame.webp`
  (рамка карты с окном под картинку + свиток под текст), `drum.webp` (барабан),
  `bowl.webp` (чаша с кубиком). Фон у рамок уже вырезан в прозрачность.
- Подключение: в `standalone/main.tsx` кнопка дока `🪷 Лила` ставит `wall='lila'`,
  и рендерит `<iframe src="/livebg/lila.html?embed=1">`. См. `docs/background-02-voxel-island.md`
  про механику переключения фонов.

## Данные: `lila-board.js`

Каждая клетка — объект:

```js
{ id, plan, name, type:'normal'|'arrow'|'snake'|'start'|'win',
  arrow_to, snake_to,            // куда ведёт стрела/змея (или null)
  prompt,                        // исходное описание (запасное)
  mirror, question,              // текущий вариант (выбирается при показе)
  variants: [[mirror, question], [mirror2, question2]], // 2 парных варианта
  choices: [...]                 // ЛЕГАСИ от старой механики, в игре НЕ используется
}
```

- 72 клетки = 8 планов по 9. `plan = ceil(id/9)`.
- Стрелы/змеи — каноничные (Хариш Джохари). `type` и `arrow_to`/`snake_to` задают переходы.
- Тексты: `MIRROR` (вариант A) и `MIRROR_B` (вариант B) — по 72 пары
  `[зеркало, вопрос]`. Цикл в конце файла кладёт их в `c.variants` и ставит
  `c.mirror/c.question = variants[0]`. При показе карты (`reveal`) выбирается
  случайный вариант из `c.variants` — чтобы при повторном попадании звучало иначе.
- Принцип текста (важно для расширения): клетка — ЗЕРКАЛО, не вердикт. `mirror` —
  короткое состояние на «ты», без оценок; `question` — ОДИН открытый вопрос,
  привязанный к запросу игрока. Никаких советов/предсказаний. См. `docs` этой игры —
  правила подачи текста.

## Игровой цикл (lila.html)

Состояние (глобальные `let`): `cur` (текущая клетка, 0 до входа), `started`, `busy`,
`request` (запрос игрока), `journal` (массив ходов), `curVia` ('вход'|'ход'|'стрела'|
'змея'), `visitedMap` ({id:{question,note}}).

Поток:

1. **Запрос.** `openRequest()` → модалка `#reqModal`. `reqGo` сохраняет `request`,
   показывает его в якоре `#reqAnchor` (верхняя панель), вызывает `openThrow()`.
   Если вход не удался (не 6) — `openRequest(true)` с текстом «Переформулируй…».
2. **Бросок (один кубик).** Чаша `#bowlWrap` (ассет + кодовый кубик `.die`).
   `pointerdown` — трясёт, `pointerup` → `doRoll()` → случай 1..6 → `resolveMove(r)`.
3. **Движение.** `resolveMove`: если не `started` — нужна 6 (→ `walk(0,1,…)` +
   `curVia='вход'`). Иначе `land=cur+r` (перелёт за 72 — ход сгорает). `walk(from,to)`
   шагает фишку (`placeAt`) по узлам с паузой, рисуя след (`trailPoint`).
4. **Приземление.** `afterLand(land)`: если у клетки `arrow_to`/`snake_to` — тост,
   пауза, перелёт на цель (`curVia='стрела'|'змея'`), пауза; иначе обычный ход.
   Затем `reveal(final)`.
5. **Карта-зеркало.** `reveal(S)`: выбирает вариант текста; показывает барабан
   (`#drumPanel.on` — появляется ТОЛЬКО сейчас), крутит ленту-слот, затем всплывает
   карта `#cardStage` (почти на весь экран) с тремя зонами: имя (жирное) / зеркало
   (белое жирное) / вопрос (коричневый). Внизу — панель заметки `#noteBar`.
   В карту вшит динамик `.spk` (ручной TTS, Web Speech API).
6. **Заметка → журнал.** `noteGo`: пушит в `journal` `{id,name,question,note,via}`,
   отмечает клетку пройденной (`visitedMap`, `.node.done`), обновляет дневник
   (`renderDiary`), прячет карту/барабан, `resetThrow()` → снова только кубик.
   На клетке 68 — `winGame()`.
7. **Победа.** `#win` со списком-журналом + кнопки «📄 Сохранить на Google Drive»
   (`journalText()` → clipboard + .txt + `docs.new`) и «Новый запрос».

## Доска, узлы, визуал

- **Два режима.** Класс `body.playing` переключается в `openThrow`/`closeAll`.
  Не играешь → фон (`#board`, картинка `board.jpg`) + фишка (`#token`). Играешь →
  поднимается матовое стекло `#glass` (над фоном, фон за ним размывается), и на нём
  видны клетки (`.node`), след (`#trail`), декор стрел/змей (`#deco`).
- **Узлы `NODES`.** 72 точки, змейкой снизу вверх, центрированный квадрат с лёгкой
  перспективой: `hw=42-row*0.9; x=50+((c-4)/4)*hw; y=86-row*9.4` (%). `drawNodes()`
  создаёт div-ы `.node` (классы `.arrow`/`.snake`/`.win` красят их). Наведение →
  тултип `#tooltip`: у непройденной клетки — название + куда ведёт стрела/змея;
  у пройденной (`visitedMap`) — вопрос + твой ответ.
- **Фишка `#token`** — светящийся шар; `placeAt(id)` двигает по CSS-транзишену.
- **След `#trail`** (SVG, координаты 0..100 = %): `trailPoint(id,kind)` добавляет
  отрезок (`step`/`arrow`/`snake` — золото/ярко-жёлтый/голубой).
- **Декор `#deco`** (SVG): `drawDeco()` рисует по линии от каждой стрелы (золото) и
  змеи (голубой пунктир) к её цели.
- **Верхняя панель.** Одной линией, выровнена по низу: `#hud` (клетка/ход, слева),
  `#reqAnchor` (запрос, центр, крупно), `#diaryBtn` (справа). Под ними — кнопка
  `#play` (переключатель «Войти ⇄ Выйти»). Доска `#glass` ниже, отступы через `calc()`.
- **Дневник `#diaryPanel`** — выезжает справа; `renderDiary()` строит пронумерованную
  стенограмму (№, клетка, тег перехода, вопрос, ответ).
- **Сохранение.** `localStorage['lila.save.v2']` = `{cur,started,request,journal}`.
  При загрузке — восстановление фишки, следа, пройденных клеток и дневника.

## Как расширять (для Кодекса)

- **Картинки в карты.** Положить `public/livebg/lila/cards/<id>.jpg` (1..72). Карта
  сама грузит её в окно `.art` (`<img class="pic" … onerror="this.remove()">`),
  иначе показывает подложку-градиент по плану. Генерировать и класть — больше ничего.
- **Третий вариант текста.** Добавить `MIRROR_C` в `lila-board.js` и в цикл сборки
  `c.variants` (сейчас берутся A+B). `reveal` сам выберет случайный.
- **Клетки-лотосы вместо точек.** Поменять оформление `.node` (сейчас радиальный
  градиент-точка) на SVG/спрайт лотоса; классы `.arrow/.snake/.win/.done` сохранить.
- **MCP/агент-ведущий.** Игра работает на фронте без LLM. Для «ведущего» (читает
  журнал, подсказывает при застревании на одной змее) — отдельный слой: отдавать
  `journal` агенту и показывать его реплику в `#noteBar`. Канал — как у Фона №2
  (`BroadcastChannel('livebg')` / postMessage), см. `docs/voxel-island-builder.md`.
- **Тон текста клеток** — строго: зеркало + один открытый вопрос к запросу, на «ты»,
  без советов и оценок (так играют настоящую «Лилу»: клетка намекает, не отвечает).
