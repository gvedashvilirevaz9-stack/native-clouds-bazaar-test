# Живые фоны — контракт для AI-агента (MCP)

Модуль: `/livebg/livebg.js` (без зависимостей). Демо: `/livebg/` (панель справа).
Встраивание в портал: импорт модуля на canvas за интерфейсом **или** iframe `/livebg/?embed=1&preset=weather&input=mouse` + `postMessage`.

## 1. Как устроено

Сцена = список слоёв снизу вверх. У каждого слоя есть `depth` от 0 до 1.2:
- `0` — бесконечно далеко, не двигается (небо);
- `1` — ближе всего, сдвигается сильнее всех (дождь, передний план).

Мышь или лицо (веб-камера) дают точку взгляда `v` в диапазоне −1…1. Каждый слой сдвигается на `−v × depth × сила`. Если наклониться к камере, ближние слои слегка увеличиваются. Из-за разницы сдвигов предметы на ближних слоях закрывают и открывают предметы на дальних — так возникает объём.

Типы слоёв:

| type | что рисует | параметры |
|---|---|---|
| `sky` | градиент неба по солнцу и погоде | — |
| `stars` | звёзды ночью | — |
| `sun` | солнце или луна по дуге восход→закат | — |
| `clouds` | облака, количество и цвет от погоды | `alt:[y0,y1]`, `scale`, `density`, `speed`, `sprites:[картинки облаков]` |
| `hills` | холмы или горы, опционально ели | `seed`, `base`, `amp`, `rough`, `color:[r,g,b]`, `haze`, `trees:{count,size}` или `trees:{list:[{u,size}]}` |
| `birds` | стая птиц днём | `count` |
| `plate` | картинка-слой на всю ширину (горы, лес, луг) | `src`, `y` (сдвиг вниз в долях экрана), `zoom`, `snow` (насколько белеет в снег) |
| `objects` | предметы | `objects:[…]`, `agent:true` — слой агента |
| `precip` | дождь или снег по погоде | — |
| `fog` | туман | — |

Эффекты поверх сцены: `glare` (луч-сканер по стеклу), `blindspot` (слепое пятно в углу, `blindCorner: auto|left|right`), гроза со вспышками.

## 2. Объект

```json
{ "id": "ship1", "kind": "airship", "x": 0.3, "y": 0.22, "size": 0.07,
  "motion": { "type": "drift", "speed": 0.6 }, "flip": false, "z": 0 }
```

- `kind`: главное — `image` с готовой картинкой из библиотеки: `"url":"objects/airship.webp"` (путь от папки `assets/`) или `https://…`.
  Анимация: `"frames":["objects/eagle_1.webp", …], "fps": 10`. Пока кадров нет, `"flap": 0.6` машет крыльями одной картинкой.
  Запасные варианты: `emoji` (+ `"emoji":"🐻"`), `svg` (+ `"svg":"<svg…>"`, до 20 КБ) и нарисованные кодом `airship`, `eagle`, `balloon`, `kite`, `plane`, `pine`.
- Библиотека сейчас: `objects/airship.webp`, `objects/eagle.webp`, `objects/balloon.webp`.
- `x`, `y` — центр объекта в долях экрана (0…1). `size` — высота объекта в долях высоты экрана.
- `motion.type`: `drift` (плывёт поперёк экрана; отрицательная скорость — в обратную сторону), `bob` (покачивается), `circle` (кружит), `none`.
- Ночью и в пасмурную погоду объекты автоматически темнеют.

## 3. Режимы доступа агента

**A. Кастомизация (сейчас).** Агент пишет **только** в слой с `agent:true`: не больше 24 объектов. Остальные слои закрыты, движок вернёт ошибку `layer "…" is locked`. Погоду, время и эффекты агент может переключать.

**B. Сцена с нуля (позже, с Grok).** Агент присылает целую сцену через `loadScene`. Что можно двигать после сборки, решим отдельно.

## 4. MCP-инструменты (предлагаемые имена)

Каждый инструмент — тонкая обёртка над `postMessage({type:'livebg', cmd, args, id})` к фону. Ответ приходит в `{type:'livebg:reply', id, ok, result|error}`.

| инструмент | cmd | args |
|---|---|---|
| `bg_get_scene` | `getScene` | — |
| `bg_add_object` | `addObject` | `[object]` |
| `bg_update_object` | `updateObject` | `[id, patch]` |
| `bg_remove_object` | `removeObject` | `[id]` |
| `bg_clear_agent_layer` | `clearAgent` | — |
| `bg_set_weather` | `setWeather` | `["live"]`, `["rain"]` или `[{cloud,rain,snow,storm,fog,wind}]` |
| `bg_set_location` | `setLocation` | `["Batumi"]` или `[{lat,lon,name}]` |
| `bg_set_time` | `setTime` | `["live"]` или `[hour, speedSecPerSec]` |
| `bg_set_effects` | `setEffects` | `[{glare,blindspot,blindCorner,birds,ground}]` |
| `bg_set_input` | `setInput` | `["mouse"]`, `["camera"]` или `["off"]`; камеру включает только сам человек кнопкой |
| `bg_load_preset` | `loadPreset` | `["sky"]` или `["weather"]` |
| `bg_load_scene` | `loadScene` | `[scene]` — только режим B |

## 5. Промпт агенту: как собирать сцену с параллаксом

```
Ты собираешь живой фон для рабочего стола. Он должен выглядеть объёмным, когда человек двигает головой.
Правила:
1. 4–8 слоёв. Снизу вверх: sky (0) → sun (0.06) → дальние облака (0.1–0.2) → дальний план, горы или лес (0.2–0.3)
   → средний план с героями (0.4–0.5) → то, что их частично закрывает (0.55–0.7) → главный герой (0.7–0.8)
   → рамка переднего плана по краям (0.9–1.0) → precip (1.0).
2. Чем ближе слой, тем крупнее предметы и тем они темнее и насыщеннее. Дальние — мельче, светлее, с дымкой (haze).
3. Эффект «выглядывает из-за дерева»: поставь объект на слой depth=d, а укрытие (дерево, камень) — на слой d+0.15…0.25
   почти в ту же точку x. При движении головы объект будет то появляться, то прятаться.
4. Передний план — только по краям (x<0.1 или x>0.9). Центр экрана оставь свободным под интерфейс.
5. Не больше 40 объектов в слое. Движение (drift/bob) — у 1–3 объектов, остальные стоят.
6. Не используй узнаваемых персонажей из мультфильмов и брендов. Только свои образы, emoji или нарисованные svg.
7. Погода и время — 'live', если человек не попросил иначе.
8. Прежде чем сохранить, перечисли человеку слои одной строкой каждый.
```

Пример полной сцены — пресет `weather` в `livebg.js`: горы 0.16 → холмы 0.3 → лес 0.5 → луг 0.88.

## 6. Камера и приватность

- Камера включается только кнопкой человека. Агент может предложить включить её, но не включает сам.
- Распознавание лица — MediaPipe Face Detector, работает в браузере. Если модель не загрузилась, включается упрощённый режим по движению в кадре. Видео никуда не отправляется.
- Камере нужен HTTPS (на Vercel он есть) или localhost.

## 7. Доставка виджетов и летающие объекты

Летающие объекты (`flyers`) — орлы, дирижабли и шары на трёх планах: `far`, `mid`, `near`.
- Для каждого объекта заранее нарезаны размеры: `assets/fly/<тип>/<кадр>_<высота>.webp`. Браузер берёт ближайший больший, ничего не уменьшает на лету.
- Каждый летит в ту сторону, куда смотрит на картинке.
- Сколько объектов на каждом плане: `setFlyers({far:{eagle:3,airship:1}, mid:{eagle:2,balloon:1}, near:{eagle:1}})`.

Курьер прилетает, зависает над точкой, сбрасывает виджет и улетает.

**Места для виджетов:** 3 ряда × 5 мест.
- Кто несёт, тот и задаёт ряд: орёл — небо (y 0.27), шар — горы (0.45), дирижабль — нижний ряд (0.64).
- Колонки x: 0.22 / 0.36 / 0.5 / 0.64 / 0.78.
- Часы всегда в центре. Остальное ложится по порядку: центр → справа → слева → дальше справа → дальше слева.
- Место бывает свободно или занято. Если занято, курьер летит к следующему свободному. Если весь ряд занят, перезаписывается самое старое.
- Если перетащить виджет рукой, он освобождает своё место.

**Размеры:**

| размер | план | прилёт | виджет |
|---|---|---|---|
| S | дальний | ~12 с, тихо плывёт | маленький |
| M | средний | ~6,5 с | средний |
| L | ближний | ~3,4 с, плавное торможение | большой |

**MCP на стенде** (`/api/mcp`):
- `background_deliver {widget, q|service, by, size, col?}` — возвращает ответ Agent Marketplace и готовую команду для страницы `{type:"livebg", cmd:"deliver", args}`;
- `background_flyers {far, mid, near}`.

Канал «сервер → открытая страница» подключается отдельно. Страница уже принимает эту команду через `postMessage`.

| инструмент | cmd | args |
|---|---|---|
| `bg_deliver_widget` | `deliver` | `["agent", {by:"eagle", size:"M", at:[0.5,0.42], data:{q:"курс биткоина"}}]` |
| | | `["clock", {by:"airship", size:"L"}]` — часы локальные, без сети |
| `bg_set_flyers` | `setFlyers` | `[{far:{eagle:3}, mid:{balloon:1}}]` |

- `data.q` — вопрос словами, его обрабатывает роутер Agent Marketplace (`/api/money?q=`). Можно и напрямую: `data:{service:"fx", params:{base:"USD"}}`.
- Виджет висит без рамки и фона. При наведении мыши появляется стеклянная рамка: виджет можно перетащить или закрыть ×. Положение запоминается в браузере.
- Примеры: «который час» → `clock`; «курс биткоина» → `agent {q:"курс биткоина"}`; «погода» → `agent {q:"погода"}`.
