# Горы — изображения для эксперимента Native Clouds

Дата: 13 ноября 2026. Это отдельный набор ассетов для Anthropic. Портал и его исходный код не изменялись.

## Сначала посмотреть

- previews/scene.png — собранный вид из подготовленных слоёв.
- previews/master.jpg — уменьшенный исходный мастер.
- previews/objects.jpg — дирижабль, шар, пять поз орла и облака.
- previews/layers.jpg — отдельные планы ландшафта.
- previews/eagle-motion.gif — предварительный цикл орла.
- assets/scene-mountains/REPORT.md — сравнение и ограничения.

## Что передать Anthropic

Передайте весь архив и попросите начать с этого README, scene.json и REPORT.md. SOURCE-PLAN.md — исходное задание, scene-passport.json — паспорт с фактическими измерениями.

Мастер и планы: **2880 × 1440 пикселей, 2:1**, без увеличения из маленькой картинки. Это не 4K.

В assets лежат 20 изображений в двух форматах:
- PNG — для просмотра, монтажа и дальнейшей обработки;
- WebP lossless — для сборки сцены в браузере.

17 изображений имеют настоящую альфа-прозрачность. Мастер, очищенный фон и небо непрозрачны. PNG и WebP — варианты одних и тех же ассетов, а не разные сцены.

## Как собирать

1. Использовать один общий холст 2880 × 1440. Масштабировать всю сцену пропорционально.
2. Путь к файлу складывается из assetBase и src/url/frames. Например, assets/scene-mountains/forest.webp.
3. Планы не обрезать: небо, горы, предгорья, лес и луг имеют одинаковый размер холста.
4. Порядок слоёв указан в scene.json: небо → горы → предгорья → дирижабль и шар → лес → орёл → луг.
5. x и y — положение точки привязки в долях холста. width — ширина полного спрайта / 2880, size — высота полного спрайта / 1440. Использовать оба размера.
6. anchor — положение точки привязки внутри спрайта. Для дирижабля и шара это центр. У орла — отдельная точка привязки; все пять кадров сохраняют общий холст 1120 × 1120. Не обрезать каждый кадр отдельно.
7. scene.json использует детализированные объекты и пять поз орла. scene-reference.json использует маленькие исходные вырезки из мастера для статического сравнения.
8. Для первого опыта с параллаксом ограничить максимальное смещение значением ±20 px и добавить 4% запаса по краям. Предварительные виды смещения лежат в previews/parallax-left.png и parallax-right.png.

В эталонном состоянии солнце-диск, дополнительные облака и осадки выключены. Освещение уже нарисовано. Три облака подготовлены отдельно для дальнейших экспериментов.

Поля time, weather, snow, motion и distance_m — описание для будущего движка. Подключения к погоде, времени, MCP и анимационному движку в этом архиве нет.

## Практические ограничения

Это экспериментальные изображения. Видимые части ландшафта сохранены из общего мастера, скрытые продолжения достроены генерацией. При больших сдвигах могут открыться следы переходов между планами. Проверка небольшого параллакса выполнена в отдельной сборке изображений, не в портале.

Высокодетальные объекты — повторная генерация по образцам. Они не совпадают с мастером пиксель в пиксель. Для точного исходного силуэта доступны airship_master, balloon_master и eagle_master. Подробности — в REPORT.md.

Генерация выполнена через OpenAI API с разрешённым пользователем ключом. Сам ключ, секреты и данные портала в архив не входят. Фактически использованная модель: gpt-image-2, качество high. Отличия от исходного задания описаны в отчёте.

MANIFEST.json содержит размеры файлов и SHA-256 для проверки целостности.
