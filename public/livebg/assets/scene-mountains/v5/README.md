# Native Clouds — согласованные слои пейзажа v5

Передний план с камнями и ромашками оставлен без изменений. Для него отдельно сгенерированы лес, предгорья и горы. Людей и персонажей нет.

## Что открыть

- `previews/composition-aligned-2880.jpg` — сборка всех слоёв, 2880 × 1440.
- `previews/parallax-check.webp` — проверка небольшого движения слоёв.
- `previews/native-detail-crops.jpg` — фрагменты исходников в масштабе 1:1, без увеличения.
- `layers/` — прозрачные PNG и WebP для сборки.
- `layout.json` — порядок, размеры, сдвиги и допустимое движение в проверенном окне.
- `prompts/` — точные промпты генерации.

## Разрешение и происхождение

Каждый слой рельефа имеет **3840 × 1920 пикселей, 2:1**. Лес, предгорья и горы получены от API в этом размере; увеличение разрешения после генерации не применялось. Использовалась `gpt-image-2.6-sunburst`, `quality=max`, `complexity=high`.

Однотонная маджента удалена с восстановлением прозрачных краёв. PNG сохраняет размер исходного ответа API. WebP записан без потерь. Передний план — побайтовая копия ранее принятого `meadow-layer-3840x1920.png`.

Старое небо сохранено в его исходном размере **2880 × 1440**. Поэтому общий просмотр сделан в 2880 × 1440: рельеф для него уменьшен до 75%, небо не увеличено. Это превью; рабочие PNG/WebP рельефа остаются 3840 × 1920.

## Сборка

Слои снизу вверх: небо → горы → предгорья → лес → передний план.

На общем холсте 3840 × 1920 задайте следующие вертикальные сдвиги. Масштаб и соотношение сторон всех слоёв рельефа одинаковые:

| Файл | X | Y |
| --- | ---: | ---: |
| mountains.png / .webp | 0 | -180 |
| foothills.png / .webp | 0 | -240 |
| forest.png / .webp | 0 | -160 |
| foreground.png / .webp | 0 | 0 |

Отрицательные сдвиги — размещение слоёв, а не растягивание изображения. Они не запечены в файлы. Нижнюю часть дальних слоёв перекрывают ближние.

Для уменьшенного холста 2880 × 1440 умножайте координаты и размеры рельефа на 0,75. Получатся Y: -135, -180, -120, 0. Небо занимает этот холст в исходном размере.

Для параллакса нужно обрезать небольшой запас по краям общего холста: в проверенном варианте 2880 × 1440 окно просмотра начинается в (64, 32) и имеет размер 2752 × 1376, также 2:1. Амплитуды каждого слоя указаны в `layout.json`. При увеличении амплитуд нужно увеличить запас; произвольные большие сдвиги не проверены.

## Передача

Архив содержит рабочие PNG/WebP, превью, промпты и метаданные. Необработанные ответы API на мадженте сохранены локально у автора и не включены в этот набор.

Это отдельный экспериментальный пакет ассетов. Файлы портала, старый `scene.json`, воздушные объекты и существующая сцена не изменялись.
